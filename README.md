# mkyia-study
MKYIA Study est une application éducative intelligente qui aide les élèves à réviser, comprendre leurs cours et réussir leurs examens. Dès le lancement, l'élève choisit son tuteur humain virtuel (professeur ou mentor adolescent) pour un accompagnement chaleureux et sur mesure à travers des quiz, fiches et explications pas à pas. 🎓✨
